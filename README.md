# Vinod Chicken & Mutton — Hyderabad

A mobile-friendly static website. No installation, npm or build needed.

## Open on your computer

Double-click index.html. Keep styles.css, script.js and the assets folder beside it.
Clipboard access depends on your browser; the enquiry text can always be selected and copied manually.

## Put it on GitHub Pages

1. Extract the ZIP on your computer.
2. Create a GitHub repository, or open your existing repository.
3. Upload ALL the extracted files and the assets folder to the repository root. Upload the files INSIDE the folder, not the ZIP itself.
4. Commit the upload.
5. Enable GitHub Pages in repository Settings, choosing the main branch and root folder as the publishing source.
6. Wait for GitHub to finish publishing, then open the website link it provides.

## Change the sample details

- Shop name, city, about text, address and hours: edit index.html.
- Products and SAMPLE prices: edit the items list at the top of script.js. Each price is per kilogram.
- Colours and layout: edit styles.css. Main colours are in :root.
- Photographs: replace assets/chicken.jpg and assets/meat.jpg with your own photos using the same filenames, or update image names in script.js and index.html.
- Menu photographs are illustrative and may not depict each exact cut. Replace them with accurate shop photos before launch.
- Update or remove the preview banner only after you verify the details.

## What works

Chicken/mutton filters, adding/removing products from an enquiry list, browser-local list saving, editable enquiry text, copy enquiry, and clear list.

## Before sharing with customers

All prices are sample prices. No real phone number, address, working hours, delivery promise, certification or reviews have been invented. Replace pending contact details with the real details. The website does not send WhatsApp messages, place orders, take payments, or save customer information on a server. Enquiry lists stay in the visitor browser. To receive WhatsApp enquiries, add your real shop number and implement a WhatsApp link.
